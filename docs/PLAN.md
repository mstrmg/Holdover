# Holdover plan (summary)

The full plan and working rules are in `CLAUDE.md`. The living plan doc: https://claude.ai/artifact/WnGBCzQrguHhMrC7VW5WbT

- Engine: Unreal Engine 5 (Lumen, Nanite), first-person C++ template.
- Art: scanned assets from Fab/Megascans for the environment; Blender for targets, props and weapons.
- Core logic in C++ with thin Blueprint wrappers, so code can be reviewed and edited as text.
- Version 1: one photoreal outdoor carbine range, pistol and carbine, paper and steel targets, 6 to 8 timed drills, body-worn camera post-processing, local personal bests.

## Repo setup on your PC

1. Install Git LFS once: `git lfs install`.
2. Create the UE5 project (Games > First Person > C++) directly in this folder, named `Holdover`.
3. Commit the `.uproject`, `Config/`, `Content/` and `Source/` folders. Everything in `.gitignore` is regenerated by the editor.
