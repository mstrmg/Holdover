# Firing effects tools

Everything you see and hear when a gun fires is generated by these scripts, then imported into Unreal. Run them in this order on Miles's PC (Unreal Editor closed for step 3):

1. `"C:\Program Files\Blender Foundation\Blender 5.3\5.3\python\bin\python.exe" -I tools/fx/gen_fx_textures.py` writes the muzzle flash and smoke textures to `art/fx/textures/`.
2. `"C:\Program Files\Blender Foundation\Blender 5.3\5.3\python\bin\python.exe" -I tools/audio/gen_gun_audio.py` writes every gun sound to `art/audio/`.
3. `UnrealEditor-Cmd.exe Holdover/Holdover.uproject -run=pythonscript -script="<repo>/tools/unreal/import_fx.py" -unattended -nop4 -nosplash -NullRHI` imports them to `/Game/FX` and `/Game/Audio` and builds the flash, smoke and brass materials.

The game finds everything by name, so nothing needs to be wired up by hand. Without the imported assets the guns still fire: only the flash's light shows and there is no sound.

Check the result with `holdover.TestShots 2` (see `docs/CONTROLS.md`).
